# ระบบจัดตารางสอนอัตโนมัติ

ต้นแบบระบบจัดตารางสอนสำหรับซ้อมแข่งขันทักษะวิชาชีพ ปวส. สาขาเทคโนโลยีปัญญาประดิษฐ์

## เปิดใช้งาน
1. รัน `python build.py`
2. เปิด `docs/index.html` ในเบราว์เซอร์
3. ล็อกอินด้วยบัญชีทดลอง

| บทบาท | ชื่อผู้ใช้ | รหัสผ่าน |
| --- | --- | --- |
| Admin | admin | admin123 |
| Teacher | t01, t02, … | 1234 |
| Student | g01, g02, … | 1234 |

## ทดสอบ
```
node test.js
```

## ขึ้น GitHub Pages
อัปโหลดโฟลเดอร์ทั้งหมดขึ้น GitHub แล้วไปที่ Settings → Pages เลือก branch `main` โฟลเดอร์ `/docs`

รายละเอียดสำหรับนักพัฒนาและ Claude Code อยู่ใน `CLAUDE.md`
