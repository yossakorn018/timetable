เข้าสู่ระบบ

สิทธิ์แบ่งเป็น 3 บทบาท: ผู้ดูแลระบบ (Admin) ครู (Teacher) และนักเรียน (Student)

บัญชีทดลอง

สำหรับกรรมการและการซ้อม กดเพื่อกรอกให้อัตโนมัติ แล้วกดเข้าสู่ระบบ

ครูทุกคนใช้ชื่อผู้ใช้ตามรหัสครู (เช่น t05) และนักเรียนใช้รหัสกลุ่ม (เช่น g03) รหัสผ่านเริ่มต้น 1234 ผู้ดูแลเปลี่ยนได้ในหน้าบัญชีผู้ใช้

ข้อมูลนำเข้า

นำเข้าไฟล์ CSV หรือ Excel ตามโครงสร้างโจทย์ 7 ตาราง ดูพรีวิวและผลตรวจก่อนบันทึก แล้วเพิ่มหรือแก้ข้อมูลต่อได้ในหน้านี้ ไม่ต้องแก้ไฟล์ใหม่

ชุดข้อมูลตัวอย่าง (ข้อมูลสมมติ)

นำเข้าไฟล์ของโจทย์

ลากไฟล์มาวาง หรือเลือกไฟล์ (เลือกได้หลายไฟล์พร้อมกัน)

ตั้งชื่อไฟล์ตามตาราง เช่น room.csv หรือใช้ Excel ไฟล์เดียวที่มีชีตชื่อ room, subject, …

ไฟล์แม่แบบ

หัวคอลัมน์ตรงกับโจทย์ทุกตัวอักษร พร้อมตัวอย่าง 2 แถวต่อตาราง

แก้ไขข้อมูล

มีการแก้ไขที่ยังไม่บันทึก

ผลตรวจข้อมูลก่อนคำนวณ

ตั้งค่าเงื่อนไข

ค่าที่อาจเปลี่ยนตามโจทย์อยู่ที่นี่ทั้งหมด ไม่ได้เขียนตายตัวในโค้ด ถ้าโจทย์วันแข่งต่างไป ให้แก้ที่หน้านี้แล้วจัดตารางใหม่

ประเภทและการแบ่งคาบของแต่ละวิชา

แยกประเภทจากชื่อวิชาก่อน (กิจกรรม → โฮมรูม → IOT) แล้วค่อยดูรหัสวิชาสามัญ · เลือกได้ว่าจะเรียนยาวต่อเนื่องหรือแบ่งเป็นช่วง เช่น 5 คาบ = 3+2

จัดตาราง

รันวิธีพื้นฐาน วิธี Heuristic และ Heuristic + วงรอบซ่อม ด้วยข้อมูลชุดเดียวกัน แล้วเทียบผลด้วยตัวตรวจ 15 ข้อ

เทียบผลกับวิธีพื้นฐาน

วิธีพื้นฐาน = จัดตามลำดับในไฟล์ ลงช่องแรกที่ว่าง ไม่สุ่ม · Heuristic = จัดวิชาที่มีข้อจำกัดมากก่อน แล้วเลือกช่องที่คะแนนโทษต่ำสุด · คะแนนคุณภาพยิ่งน้อยยิ่งดี

บันทึกวงรอบซ่อม

วิชาที่วางไม่ได้

ผลแต่ละรอบ (seed)

ตรวจ 15 เงื่อนไข

ตัวตรวจแยกจากตัวจัดตาราง ตรวจผลลัพธ์ทุกแถวกับข้อมูลโจทย์ กดที่เงื่อนไขเพื่อดูรายการที่ผิดและวิธีแก้

ตารางสอน

ลากวิชาไปช่องว่างเพื่อย้าย หรือวางทับวิชาอื่นเพื่อสลับ ระบบตรวจเงื่อนไขให้ก่อนวางทุกครั้ง บนมือถือให้แตะวิชาแล้วแตะช่องปลายทาง

แจ้งเวลาไม่สะดวกสอน

แตะช่องเพื่อสลับ สะดวก / ไม่สะดวก แล้วกดบันทึก ระบบจะไม่จัดวิชาลงช่องที่ไม่สะดวกในการจัดตารางครั้งถัดไป และห้ามลากวิชาไปวางทับ

ไม่สะดวกมีสอนอยู่มีสอนแต่แจ้งไม่สะดวก (ต้องจัดใหม่)

บัญชีผู้ใช้

ครูและนักเรียนได้บัญชีอัตโนมัติจากข้อมูลครูและกลุ่มเรียน รหัสผ่านเก็บเป็นค่า hash (SHA-256 + salt) ไม่เก็บรหัสจริง

ภาระครูและการใช้ห้อง

ตัวชี้วัดช่วยตัดสินใจ เช่น ครูคนไหนสอนหนัก ห้องไหนว่างมาก กลุ่มไหนเรียนหนักวันใด
